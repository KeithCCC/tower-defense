# WAYPOINT — Maze Defense

砲台で迷路をつくり、左右・上下の2経路から来る10のWaveを守り抜く、ブラウザ向けTower Defenseです。v0.2では敵の役割と対策を取り入れました。Classic Desktop Tower Defense (2007) に着想を得た独自ルールであり、原作の正確なWave順・数値・各バージョンの再現ではありません。画像・音楽・ロゴ・ゲームコードは流用せず、CanvasとCSSによる独自の仮素材で実装しています。

バックエンド・アカウント・有料サービス・外部アセットへの通信は不要です。

## 開発

Node.js **22.12以上**（検証環境: 24.19.0）とnpmを使用します。

```sh
npm ci
npm run dev
```

Viteが表示するアドレスをブラウザで開きます。同一ネットワークのiPhoneから確認する場合は、開発PCのLANアドレスとポート5173を使用してください。開発サーバーは既定で全インターフェースを使用します。ローカル限定にする場合は `npm run dev -- --host 127.0.0.1` を使用します。

```sh
npm test               # Vitest: DOMから独立したゲーム・経路・入力座標のテスト
npm run test:watch     # Vitestの監視モード
npm run build         # TypeScriptの型チェックと本番ビルド
npm run preview       # distの確認
```

`npm run build` はJavaScript・CSSを埋め込んだ単一HTMLを `dist/waypoint.html`（および `dist/index.html`）に生成します。チャットのHTMLプレビューや、サーバーを起動せずに遊ぶ場合は、このビルド済みファイルを開いてください。リポジトリ直下の `index.html` はVite用の入口であり、単体では動作しません。プレビュー側でJavaScript自体が禁止されている場合は、ダウンロードしたHTMLを通常のブラウザで開いてください。

GitHub Actionsの成功した実行からも、Artifactsの `waypoint-single-html` をダウンロードできます。

ブラウザテスト:

```sh
npx playwright install chromium
npm run test:e2e
```

ブラウザテストは最初にビルドを実行します。通常のVite経由の操作に加え、単一HTMLを外部通信をすべて拒否した文書へ読み込み、起動・配置・強化・売却・Wave開始を検証します。

既存の `/usr/bin/chromium` があれば自動的に利用します。別の実行ファイルは `CHROMIUM_PATH` で指定できます。Linuxでブラウザの共有ライブラリがない場合は、Playwrightの案内に従って `npx playwright install --with-deps chromium` を実行します。

クラウド環境などで標準のnpmキャッシュを書き込めない場合は、`npm --cache /workspace/.cache/npm ci` を使用できます。

## 遊び方

1. 建設パネルで砲台の種類を選び、空きマスをクリック / タップして配置します。初期資金140 Cです。
2. 次Waveの敵と対策を確認して「Waveを開始」。左右・上下の入口から交互に出現し、それぞれ反対側の出口へ進みます。
3. 砲台を選択すると射程を表示し、強化・売却ができます。戦闘中や一時停止中も操作できます。
4. 敵の撃破とWaveクリアで資金獲得。10 Waveを終え、ライフが残っていれば勝利です。

- **地上の移動:** 上下左右の4方向。左右は `(0,5) → (15,5)`、上下は `(7,0) → (7,11)`（座標は0始まり）。各出口への距離マップを別々に計算し、配置・売却のたびに更新します。
- **配置制限:** 4つの出入口・既存砲台・地上敵の現在マスと移動先には配置できません。どちらかの入口や地上敵を、その敵の出口から切り離す配置も資金を消費せず拒否します。飛行敵が通過中のマスには配置できますが、地上経路の制限は常に有効です。
- **強化:** 全4種類をLv.3まで強化できます。キャノンは30 C → 50 C、迫撃砲は40 C → 60 C、対空砲は30 C → 50 C、冷却砲は35 C → 55 C。射程・火力・連射性能、範囲・減速も種類に応じて上がります。
- **売却:** 配置と強化に投じた合計額の70%（端数切り捨て）を返金します。
- **ライフ:** 初期20。出口に到達した敵1体ごとに1減り、0で敗北です。
- **敵:** 通常、集団、高速、飛行、耐性、分裂、ボス。分裂型を撃破すると小型2体がその場に出現し、元の進路・出口を引き継ぎます。逃した分裂型は分裂せずライフを1削ります。小型は再分裂せず、それぞれ撃破報酬・ライフ減少の対象です。
- **進行:** 各Waveは手動開始。1×/2×、一時停止、最初からやり直す操作があります。タブを離れた時間は進行に加算しません。
- **キーボード:** フィールドにTabでフォーカスし、矢印キーでカーソル移動、Enter / Spaceで配置または選択、Escapeで選択解除。強化などはHTMLボタンから操作します。

### 砲台の役割

| 砲台 | 配置費用 | 攻撃対象と特徴 |
| --- | --- | --- |
| キャノン | 20 C | 地上単体。耐性型やボスへの直接火力 |
| 迫撃砲 | 35 C | 地上範囲。密集した集団型・分裂後の小型をまとめて攻撃 |
| 対空砲 | 25 C | 飛行専用。地上敵には攻撃しない |
| 冷却砲 | 30 C | 地上単体を1.4秒減速。耐性型には減速せず、直接ダメージのみ |

飛行型は砲台と迷路を無視して直進し、**対空砲だけ**が攻撃できます。冷却砲の減速は重ねても強い効果だけが有効で、効果時間を更新します。全種類の砲台が地上敵の障害物になります。

### Wave構成

1. 通常9体（2方向の基本防衛）
2. 集団18体（3体ずつの密集隊列）
3. 高速12体
4. 飛行10体
5. 通常8体 + ボス2体（各方向1体）
6. 耐性14体
7. 分裂8体（撃破すると小型が最大16体追加）
8. 集団6 + 高速4 + 耐性4 + 分裂4
9. 飛行6 + 高速6 + 耐性4
10. 通常4 + 耐性4 + 分裂2 + 飛行6 + ボス2

全Waveの予告と敵の特徴・対策をゲーム内にも表示します。最初は中央付近に地上用砲台を集めて両方向を迎撃し、Wave 2に迫撃砲、Wave 4までに対空砲を用意するのが基本です。初期資金と獲得報酬だけで勝利する具体的な編成を `tests/balance.test.ts` で検証しています。

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/game/pathfinding.ts` | 逆方向BFSによる距離マップと4方向の経路 |
| `src/game/definitions.ts` | 砲台・敵の数値、役割と対策、2経路、全Waveの出現リスト |
| `src/game/model.ts` | 固定1/60秒のシミュレーション、配置判定、戦闘、Wave、資金 |
| `src/view/renderer.ts` | 状態を変更しないCanvas描画・DPR対応 |
| `src/view/input.ts` | ポインター座標からグリッドへの変換 |
| `src/main.ts` | HTMLコントロール、ポインター・キーボード入力、画面更新 |
| `tests/` | Vitestによるロジックの回帰テスト |
| `e2e/` | Playwrightによる実際のクリック・タップ操作 |

## 検証範囲

2経路の閉塞拒否・移動中の再探索、資金・強化上限・全砲台の返金、射程・クールダウン、対空フィルタ・範囲攻撃・減速と耐性、分裂後の位置・進路・報酬・Wave完了、予告と実際の出現リストの一致、勝敗・再開始をVitestで検証します。初期資金と獲得報酬だけで10 Waveを勝利できるシミュレーションも含みます。Playwrightはデスクトップ、390×844のモバイル縦画面、844×390の横画面で、全砲台の選択・配置・強化・売却、予告・敵の説明、閉塞拒否、戦闘・停止・再開、キーボード操作と横方向のはみ出しを確認します。

iPhoneの操作を考慮したレスポンシブUIとPointer Eventsを使用しています。自動テストはChromiumでのモバイルエミュレーションです。**実機iPhone / Safariでの動作は未検証**です。画面読み上げには状態やボタンのラベルを用意していますが、非視覚的なゲームプレイ全体は保証していません。

## 現在の範囲

砲台4種類、各3段階のレベル、7役の敵と分裂後の小型、2経路・10 Waveの固定ルールです。音声、セーブ、ランキング、追加マップは含みません。ゲームの数値は初期調整段階です。iPhone向けの公開URLを新たに作成・公開する作業は、この変更には含みません。

既存のApache-2.0ライセンスを維持しています。
