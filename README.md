# WAYPOINT — Maze Defense

砲台で迷路をつくり、10のWaveを守り抜く、ブラウザ向けのTower Defenseプロトタイプです。Classic Desktop Tower Defense (2007) の迷路構築に着想を得ています。画像・音楽・ロゴ・ゲームコードは流用せず、CanvasとCSSによる独自の仮素材で実装しています。

バックエンド・アカウント・有料サービス・外部アセットへの通信は不要です。

## 開発

Node.js **22.12以上**（検証環境: 24.19.0）とnpmを使用します。

```sh
npm ci
npm run dev
```

Viteが表示するアドレスをブラウザで開きます。同一ネットワークのiPhoneから確認する場合は、開発PCのLANアドレスとポート5173を使用してください。開発サーバーは既定で全インターフェースを使用します。ローカル限定にする場合は `npm run dev -- --host 127.0.0.1` を使用します。

```sh
npm test               # Vitest: DOMから独立したゲーム・経路・入力座標のテスト
npm run test:watch     # Vitestの監視モード
npm run build         # TypeScriptの型チェックと本番ビルド
npm run preview       # distの確認
```

ブラウザテスト:

```sh
npx playwright install chromium
npm run test:e2e
```

既存の `/usr/bin/chromium` があれば自動的に利用します。別の実行ファイルは `CHROMIUM_PATH` で指定できます。Linuxでブラウザの共有ライブラリがない場合は、Playwrightの案内に従って `npx playwright install --with-deps chromium` を実行します。

クラウド環境などで標準のnpmキャッシュを書き込めない場合は、`npm --cache /workspace/.cache/npm ci` を使用できます。

## 遊び方

1. 空きマスをクリック / タップしてキャノンを配置します。初期資金140 C、1基20 Cです。
2. 「Waveを開始」で敵が入口から出現。砲台は射程内の敵を自動攻撃します。
3. 砲台を選択すると射程を表示し、強化・売却ができます。戦闘中や一時停止中も操作できます。
4. 敵の撃破とWaveクリアで資金獲得。10 Waveを終え、ライフが残っていれば勝利です。

- **移動:** 上下左右の4方向。砲台は障害物となり、配置・売却のたびに最短経路を再計算します。
- **配置制限:** 入口・出口・既存砲台・敵の現在マスと移動先には配置できません。入口や移動中の敵の出口への道を塞ぐ配置も拒否し、資金を消費しません。
- **強化:** Lv.2は30 C、Lv.3は50 C。攻撃力・射程・連射性能が上がります。
- **売却:** 配置と強化に投じた合計額の70%（端数切り捨て）を返金します。
- **ライフ:** 初期20。出口に到達した敵1体ごとに1減り、0で敗北です。
- **敵:** 通常部隊、高速部隊、Wave 5・10の最後に出現する重装部隊。
- **進行:** 各Waveは手動開始。1×/2×、一時停止、最初からやり直す操作があります。タブを離れた時間は進行に加算しません。
- **キーボード:** フィールドにTabでフォーカスし、矢印キーでカーソル移動、Enter / Spaceで配置または選択、Escapeで選択解除。強化などはHTMLボタンから操作します。

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/game/pathfinding.ts` | 逆方向BFSによる距離マップと4方向の経路 |
| `src/game/model.ts` | 固定1/60秒のシミュレーション、配置判定、戦闘、Wave、資金 |
| `src/view/renderer.ts` | 状態を変更しないCanvas描画・DPR対応 |
| `src/view/input.ts` | ポインター座標からグリッドへの変換 |
| `src/main.ts` | HTMLコントロール、ポインター・キーボード入力、画面更新 |
| `tests/` | Vitestによるロジックの回帰テスト |
| `e2e/` | Playwrightによる実際のクリック・タップ操作 |

## 検証範囲

経路閉塞・移動中の再探索・敵の閉じ込め防止、資金不足、強化上限・返金、射程・クールダウン・報酬、Wave待機・全10 Wave・敗北・再開始をVitestで検証します。Playwrightはデスクトップ、390×844のモバイル縦画面、844×390の横画面で、配置・強化・売却、閉塞拒否、戦闘・停止・再開、キーボード操作と横方向のはみ出しを確認します。

iPhoneの操作を考慮したレスポンシブUIとPointer Eventsを使用しています。自動テストはChromiumでのモバイルエミュレーションです。**実機iPhone / Safariでの動作は未検証**です。画面読み上げには状態やボタンのラベルを用意していますが、非視覚的なゲームプレイ全体は保証していません。

## 初版の範囲

砲台1種類、3段階のレベル、10 Waveの固定ルールです。音声、セーブ、ランキング、飛行敵、追加マップは含みません。ゲームの数値は初期調整段階です。

既存のApache-2.0ライセンスを維持しています。
